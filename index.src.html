Infrastruttura di Erogazione e Implicazioni per la Privacy:
La modalità di erogazione di questa risorsa e il conseguente trattamento dei dati di navigazione variano in base all'URL utilizzato:

  • Accesso tramite aenigma.criptasemantica.it: In questo scenario, la pagina viene servita dal server italiano di criptasemantica.it per mezzo di un reverse proxy. Tecnicamente, il server agisce da gateway: riceve la connessione terminando il protocollo SSL/TLS e inoltra la richiesta all'origine. Ciò significa che i metadati della vostra connessione (indirizzo IP, User-Agent, timestamp) vengono processati e conservati nei log di sistema unicamente sul server italiano. Questo meccanismo garantisce che il trattamento temporaneo dei dati di traffico sia interamente soggetto alla giurisdizione italiana ed europea, in totale conformità e tutela del GDPR (Regolamento UE 2016/679), impedendo l'esposizione diretta all'infrastruttura sottostante.
  • Accesso tramite finai-is-not-an-influencer.github.io: Visitando questo dominio, la pagina viene servita in forma diretta dall'infrastruttura di hosting GitHub Pages. Conseguentemente, le richieste HTTP dell'utente raggiungono direttamente i server di GitHub (Microsoft Corporation). GitHub raccoglie e processa in automatico l'indirizzo IP, log di accesso e telemetria essenziale a fini di sicurezza ed elaborazione statistica. Tali dati personali possono essere trasferiti e archiviati in server situati negli Stati Uniti d'America, comportando un trasferimento extra-UE. Vi invitiamo attentamente a leggere la GitHub General Privacy Statement e i relativi Termini di Servizio per conoscere come Microsoft tratta tali dati, le basi giuridiche adottate e i rischi intrinseci legati all'archiviazione extra-europea.

La rete ontologica mondiale d'informazione della Cripta Semantica

La rosa sostanziale esiste oramai soltanto nel suo nome; a noi non restano che nudi nomi.

Aenigma è l'ontologia web della Cripta Semantica. La parte d'iperscrittura dell'ontologia fondamentale cui appartiene l'essere informatico si svolge all'interno di Aenigma. Il proposito di questa ontologia web è la realizzazione dei presupposti materiali di una ontologia analitica totale, nonché il progresso delle tecnologie inferenziali e della ricerca scientifica. Lo strumento finale potrà essere utilizzato per studio, capitalizzazione semantica, qualificazione scientometrica, posizionamento nella rete, marketing, sviluppo dell'intelligenza, lavori derivativi, ricerca filosofica.

Stato corrente
